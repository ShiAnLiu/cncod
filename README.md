# 华语 Huayu
> 会说话，就会编程。
> 一门用白话文写程序的中文编程语言。
>
> 仓库名 **cncod** 是 "Chinese code" 的缩写——仓库标识用英文以适配 GitHub，
> 下载后的代码本身全部是中文：解释器是 `华语.py`，源文件扩展名是 `.华语`。
定 价格 为 3。
定 数量 为 4。
显示 "一共 " 加 价格 乘 数量 加 " 元"。    → 一共 12 元
## 为什么做华语
很多人卡在编程第一关的不是逻辑，而是英语：变量、函数、循环，每个词都得先学英文。
华语把这一关拆掉——**句子怎么说，程序就怎么写**。它的野心很朴素：
- 给第一次接触编程的孩子和大人，一条没有英语门槛的路；
- 给语音输入时代一个自然的选择——不依赖空格和缩进，念出来就是代码；
- 给只想解决小问题的普通人，一个拷贝就能跑、报错说人话的工具。
## 设计目标
1. **句子思维**：程序就是一段话，每句话以句号「。」结尾；
2. **语音与手写都友好**：全角半角符号都认，空格可有可无（`定X为5。` 合法）；
3. **报错说人话**：`[第 3 行] 变量「甲」还没有定义` —— 中文、带行号、带建议；
4. **一个文件，零依赖**：整个语言就是一个 `华语.py`，只依赖 Python 标准库，
   Windows / macOS / Linux / 安卓（Termux）都能跑；
5. **双后端，同一语义**：既能解释执行，也能编译成独立 Python 程序。
## 快速开始
环境要求：Python 3.6+，无任何第三方依赖。
```bash
git clone https://github.com/ShiAnLiu/cncod.git
cd cncod
python 华语.py 我的程序.华语        # 运行一个程序
python 华语.py                     # 进入交互模式（REPL）
python 华语.py --编译 我的程序.华语 # 编译成独立的 我的程序.py
```
交互模式长这样：
```
华语> 定 名字 为 "世界"。
华语> "你好，" 加 名字
→ 你好，世界
```
编译出来的 `.py` **不需要华语.py 就能独立运行**，发给别人即可。
## 五分钟学会
> 把示例存成 `演示.华语`（UTF-8 编码）即可运行。行与行之间换行、缩进都只是好看，语法不依赖它们。
### 变量
```
定 名字 为 "小明"。     「用 定 创建」
定 年龄 为 12。
设 年龄 为 年龄 加 1。  「用 设 修改已存在的」
```
### 判断
```
若 年龄 大于等于 18 则
    显示 "成年人"。
否则
    显示 "未成年人"。
结束。
```
### 循环
```
定 总和 为 0。
定 i 为 1。
当 i 小于等于 100 重复
    设 总和 为 总和 加 i。
    设 i 为 i 加 1。
结束。
显示 总和。              → 5050
```
### 函数
```
定义 问好(名字)
    返回 "你好，" 加 名字 加 "！"。
结束。
显示 问好("小红")。       → 你好，小红！
```
### 列表和文本
```
定 水果 为 【"苹果"，"香蕉"，"橘子"】。
显示 取(水果, 2)。        → 香蕉   「序号从 1 开始」
加入(水果, "西瓜")。
写入(水果, 1, "葡萄")。
显示 长度(水果)。         → 4
显示 取字符("你好", 1)。  → 你
显示 字(65)。             → A
```
### 结构体（把变量和方法打包成一个对象）
```
结构 点
    定 x。                「字段：没有默认值，构造时必须给」
    定 y 为 0。           「字段：有默认值，可省略」
    定义 平方和(自己)      「方法：第一个参数是"自己"（同 Python 的 self）」
        返回 自己·x 乘 自己·x 加 自己·y 乘 自己·y。
    结束。
结束。
定 甲 为 点(3)。           「括号里的值按字段顺序填入」
显示 甲·平方和()。         → 9
设 甲·y 为 4。             「成员赋值」
显示 甲·平方和()。         → 25
显示 甲。                  → 点(x=3，y=4)
```
### 库（导入别人写好的，或自己发布）
```
导入 圆周率。              「库文件 圆周率.华语 已安装到 华语库/ 文件夹」
显示 圆周率·面积(2)。      → 12.56636
```
写一个库 = 写一个普通华语文件，顶层的变量、函数、结构体自动成为库的成员。
库还能导入库。安装与卸载在交互模式完成：
```
包 安装 圆周率.华语    「安装」
包 列表                「查看已安装」
包 移除 圆周率         「卸载」
```
### 注释
```
「这是注释，可以写一整句话，甚至跨行。」
显示 1 加 1。  「行尾注释也可以」
```

## 设计取舍（问答）
**为什么每句话以句号结尾？** 因为华语把程序当文章写。句号让「一句话在哪结束」
永远明确，也换来了不依赖换行和缩进的自由——语音口述一段程序，念到句号自然停顿。
**为什么用「·」访问成员？** 英文句点 `.` 已经被句号占用了，间隔号「·」是中文里
现成的分隔符号，不用另造符号。
**为什么方法的第一个参数要显式写「自己」？** 和 Python 的 self 同理：把"谁在
做这个动作"写在明面上，初学者不用背隐藏规则。
**默认值要注意什么？** 默认值在定义时只算一次。`定 标签 为 【】。` 意味着所有
实例共享同一个列表——要各用各的，构造完再单独赋值。
**仓库名为什么是 cncod？** GitHub 仓库标识用英文更稳妥，cncod = Chinese code。
语言本身叫"华语"：下载后解释器是 `华语.py`，源文件是 `.华语`，报错、文档全是中文。
## 已知限制（诚实版）
- **普通变量名**请避免以关键字开头（如 `设`、`为`、`当`、`若`、`加`、`减`……），
  否则取值时会被切碎。**字段名、方法名、库名不受此限制**（v0.6.1 已修好）；
- 编译模式下，名字不能恰好撞上 Python 的关键字（会得到明确的报错提示）；
- 数字用阿拉伯数字书写（支持 `3.14`，暂不支持「三点一四」）；
- 尚无错误处理机制（类似 try/catch）、无命名参数，均在路线图中。
## 运行原理
`华语.py` 单文件实现，四个阶段：**切词**（把汉字词流切成记号）→
**解析**（生成语法树）→ 两条后端：**解释器**直接遍历语法树执行；
**编译器**把语法树翻译成 Python 源码，内嵌一个小型运行时，再用 Python 自带
的 `compile` 生成字节码。两个后端行为对拍一致。
